# Campus — Студентська платформа оголошень

Вебплатформа (аналог OLX) для студентів і викладачів для швидкого продажу/купівлі речей, обміну конспектами та пошуку сусідів у гуртожиток.

## Проблема, мета й цільова аудиторія
- **Проблема:** Відсутність єдиної зручної платформи для локального студентського ринку; поточні рішення перевантажені або не адаптовані під швидкі потреби студентів.
- **Мета:** Створити зручний сервіс для публікації студентських оголошень з урахуванням сучасних вимог до швидкості інтерфейсу.
- **Цільова аудиторія:** Студенти та викладачі університету.

## Ролі користувачів
1. **Гість** — перегляд публічних сторінок та оголошень.
2. **Користувач** — створення, редагування та видалення власних оголошень, зв'язок із продавцями.
3. **Модератор** — перевірка контенту та опрацювання скарг.
4. **Адміністратор** — повне керування користувачами та системою.

## Основні функції та сторінки
- Авторизація та профіль.
- Каталог із фільтрацією та пошуком.
- Сторінка створення оголошення.
- Адмін-панель та модерація.
